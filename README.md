# Make the AI judge feel brave

A short, quiet text built around a single still scene — a kettle just clicked off, steam rising in window light — written so the calm and steadiness come from the image itself rather than from any instruction. Running `main.py` writes the entry text to `/output/entry.txt` as UTF-8, using only the Python standard library.
